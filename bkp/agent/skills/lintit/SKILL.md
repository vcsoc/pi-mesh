# Lintit Workflow

When modifying code:

1. Detect project type.
2. Run appropriate lint command:
   - TypeScript: npm run lint
   - Python: ruff check .
   - C#: dotnet format --verify-no-changes
3. Report findings.
4. Attempt automatic fixes where safe.
5. Re-run linting.
6. Present final clean result.---
